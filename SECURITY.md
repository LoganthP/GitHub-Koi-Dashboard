# Security policy

Do not commit personal access tokens, API keys, private events, or credential-bearing URLs. This project runs in the browser and all client-side configuration is public.

For vulnerabilities, contact the repository maintainer privately through their GitHub profile or GitHub private vulnerability reporting if enabled. Do not publish exploitable details before a fix is available.

The dashboard uses public GitHub API responses and a third-party contributions endpoint; do not treat these APIs as private or authoritative account analytics.
